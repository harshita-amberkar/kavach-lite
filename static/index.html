              ✳
              
Local AI review

              
The optional local AI reviewer provides advisory assessments. It does not control the detector or masking decisions.

              
Availability is controlled by the KAVACH server configuration, including KAVACH_AGENT_ENABLED and the local Ollama service. This dashboard cannot switch the server setting independently.

            


            

              ⌂
              
Local server and access

              
For development, bind KAVACH to 127.0.0.1 and do not expose it to a public network.

              
The dashboard uses an API access token. Do not share it, hardcode it, or commit it to Git.
