04 / SETTINGS
Security & privacy
Know where KAVACH runs and what its current protections do.

          
⌂
Local server
For development, bind KAVACH to 127.0.0.1 and do not expose it to a public network.
♢
API access token
The dashboard includes a token in API calls. Avoid sharing it, hardcoding it, or committing it to Git.
✳
Advisory AI
The LLM review is optional and advisory. Detection and masking remain controlled by KAVACH's scanner.
