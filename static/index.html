KAVACH FOR CHROME

                
Protect prompts as you type

                
The extension checks prompts in ChatGPT, Claude and Gemini before you send them. Choose whether supported matches should be allowed, warned about, masked or blocked.

                Download extension (ZIP)
                

                  
Install the extension

                  
    
                    
  1. Download and unzip the file.
    2. 
                    
  2. In Chrome, open chrome://extensions and turn on Developer mode.
    3. 
                    
  3. Select Load unpacked, then choose the unzipped KAVACH folder containing manifest.json.
    4. 
                    
  4. To change extension preferences, open KAVACH's Details page and select Extension options.
    5. 
                  

                

                
Extension preferences are separate from dashboard settings. Changing one does not change the other. Possible Aadhaar matches always show a warning.
